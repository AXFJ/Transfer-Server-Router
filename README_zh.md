## 简介

Transfer Server Router 是一个极其轻量级的 Minecraft 服务器路由工具。它在玩家一旦连接到服务器时发送转移数据包（同等于原版 `/transfer` 命令），将玩家快速重定向到指定的目标服务器。该工具可用于给服务器进行入口分流或在**虚拟局域网下强制玩家使用公网IP（请参考我的另一个仓库 `Radmin-VPN-Minecraft-Server-Force-Join-with-Public-IP`）**的场景。

**目前稳定协议支持**：Minecraft 1.21.11（协议版本 774），可配置兼容其他版本。

---

## 特性

- 可配置连接限制：
  - 全局最大并发连接数
  - 每个 IP 的最大并发连接数
  - 每个 IP 的请求速率限制（次/秒）
- 连接超时设置，避免僵死连接
- 协议版本校验警告（可配置）
- 清晰的配置文件
- 结构化日志输出，包含时间戳、等级、IP 和消息

## 配置文件

首次启动时，程序会在当前目录自动生成 `tsr_server.properties` 文件，内容为默认配置。你可以根据需要修改各项参数。

### 配置项说明

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ip` | 字符串 | `0.0.0.0` | 服务监听 IP 地址 |
| `port` | 整数 | `25565` | 服务监听端口 |
| `target-ip` | 字符串 | `example.com` | 目标服务器 IP 或域名 |
| `target-port` | 整数 | `25565` | 目标服务器端口 |
| `protocol` | 整数 | `774` | 期望的客户端协议版本。与客户端版本不匹配时会记录警告，但不会拒绝连接。 |
| `max-conn` | 整数 | `5` | 全局最大并发连接数 |
| `max-conn-per-ip` | 整数 | `2` | 每个 IP 允许的最大并发连接数 |
| `rate-per-ip` | 浮点数 | `1.0` | 每个 IP 每秒允许的请求数（|
| `timeout-per-conn` | 整数 | `15` | 每个连接的超时时间（单位：秒）|

以及一些 SLP 选项。

## 快速开始

### 1. 准备脚本

在终端中执行：

```bash
cargo build
```

首次启动会自动创建默认配置文件 `tsr_server.properties`，并根据配置开始监听。

### 3. 停止服务

在运行的控制台中输入 `stop` 并回车。
